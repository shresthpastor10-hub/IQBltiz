⚡ IQBlitz

Compete. Practise. Sharpen your mind.

IQBlitz is an online brain-training platform where you can challenge real players in live quiz battles or train solo against a bot. Questions span Physics, Maths, Biology, Chemistry and General Knowledge (GK), helping you build speed, focus, memory and problem-solving skills.

🎯 Purpose

Many of us struggle with a foggy, distracted mind. IQBlitz turns mental exercise into a fast, fun daily habit. Regular practice with quick-fire, thought-provoking questions can help you:

Improve concentration and mental clarity
Strengthen recall and reasoning
Build speed and accuracy under pressure
Stay curious and consistently challenge your brain

Note: IQBlitz is an educational and recreational platform. It is not a medical tool and does not diagnose, treat or cure any health condition. If you experience persistent brain fog or cognitive concerns, please consult a healthcare professional.

✨ Features
🆚 Multiplayer Battles – Compete against online players in real-time quiz duels.
🤖 Practice vs Bot – Train anytime against an AI bot with adjustable difficulty.
📚 Multiple Subjects – Physics, Maths, Biology, Chemistry and General Knowledge.
⏱️ Timed Rounds – Quick "blitz" format to boost thinking speed.
🏆 Leaderboards – Climb the rankings and track your progress.
📈 Performance Stats – View accuracy, speed and subject-wise improvement.
🔥 Daily Streaks – Build a consistent brain-training habit.
🧠 Game Modes
Mode	Description
Online Battle	Match with a live opponent and race to answer correctly.
Bot Practice	Solo practice against a bot, no pressure, great for learning.
Topic Challenge	Focus on one subject (e.g., only Physics or Maths).
Mixed Blitz	Random questions from all subjects for the ultimate test.

🚀 Getting Started
Prerequisites
Node.js (v18 or later)
npm or yarn
A database instance (MongoDB / PostgreSQL)

Installation
bash
# Clone the repository
git clone https://github.com/your-username/iqblitz.git

# Move into the project folder
cd iqblitz

# Install dependencies
npm install
Environment Variables

Create a .env file in the root directory:

env
PORT=3000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
Run the App
bash
# Development
npm run dev

# Production
npm start

Open http://localhost:3000 in your browser.
